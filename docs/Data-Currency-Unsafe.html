newtype Currency #

ISO 4217 currency.

Constructors

Currency Word32

Alpha code is stored in bits 0-14, each letter taking up 5 bits (representing A-Z as values 1-26).

Numeric code is stored in bits 16-27, each digit taking up 4 bits (representing digits as values 0-9).

Minor unit count is stored in bits 28-31.

Bit coverage: DDDD'NNNN'NNNN'NNNN'XAAA'AAAA'AAAA'AAAA.
